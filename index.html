1. 결제 안내 (금액 계산기)

[ 📝 결제 안내문 양식 설정 ]

양식에 아래의 키워드를 입력해 두면 계산기 내용이 자동으로 적용됩니다.
{버튼} : 선택한 버튼 이름들 (예: (전신) + (소품 추가×3))
{개별 금액} : 선택한 버튼 금액들 (예: (50,000) + (10,000×3))
{최종 금액} : 전체 금액 비율을 적용한 최종 금액

현재 총액: 0원
